---
title: 알림함
description: 검사와 검토 알림 확인, 읽음·보관, 수신 설정
---

로그인 후 상단 벨에서 최근 알림 5개를 확인하고 **전체 알림 보기**로 `/notifications`에 이동합니다. 미읽음 배지는 99개까지 숫자로, 그 이상은 `99+`로 표시합니다. 알림은 최근 90일간 제공됩니다.

## 어떤 알림을 받나요?

| 상황 | 수신 대상 |
| --- | --- |
| 검사 완료 · 실패 · 취소 | 검사를 요청한 사용자 |
| 새 검토 요청 | 활성 상태의 검토 자격 보유자, 신청자 제외 |
| 검토 승인 · 반려 | 해당 검토 신청자 |
| 새 공개 코멘트 | 검사 소유자와 해당 검토의 결정자, 작성자 제외 |

관리자 역할과 검토 자격은 독립적입니다. 관리자라도 검토 자격이 없으면 검토 요청 알림을 받지 않습니다. 내부 코멘트는 알림을 생성하지 않습니다. 캐시를 이용한 검사 완료, 실행 실패·시간 초과, 취소 및 재시작으로 중단된 검사도 알림 대상입니다. 도입 전 완료된 작업의 알림을 소급 생성하지는 않습니다.

## 읽음과 보관

- 벨을 여는 것만으로 읽음 처리하지 않습니다. 알림을 열면 읽음 처리 후 해당 검사 또는 검토 상세로 이동합니다.
- **전체 / 안 읽음 / 보관함**과 **알림 유형** 필터를 조합할 수 있습니다. 한 페이지에 25개를 표시합니다.
- 개별 항목에서 **읽음으로 표시 / 안 읽음으로 표시**를 전환합니다.
- **모두 읽음**은 현재 유형 필터에 해당하는 모든 페이지에 적용합니다. 조회 시점에 커밋된 수신자별 순번까지만 적용하므로 늦게 저장이 완료된 새 알림과 보관함은 읽음 처리하지 않습니다.
- **보관**하면 일반 목록과 미읽음 배지에서 제외합니다. 보관함에서 복원할 수 있으며 기존 읽음 상태를 유지합니다.
- 통신 오류가 발생하면 성공으로 표시하거나 자동 이동하지 않습니다. 오류를 확인하고 다시 시도하세요. 배지의 `!`는 미읽음 개수를 갱신하지 못했다는 뜻입니다.

## 수신 설정

알림함의 **알림 설정** 탭 또는 사용자 설정의 **알림 수신 설정**에서 검사 소식, 검토 요청, 검토 결과, 코멘트를 각각 켜고 끕니다. 기본값은 모두 켜짐입니다. 설정은 계정에 저장되어 다른 브라우저에서도 적용되며, 앞으로 생성되는 알림에만 영향을 줍니다. 변경한 항목만 저장하므로 다른 기기에서 바꾼 나머지 항목을 덮어쓰지 않습니다.

화면이 보이는 동안 30초 간격으로 새 소식을 확인합니다. 탭 복귀와 네트워크 재연결 때도 갱신하며 **새로고침**으로 즉시 조회할 수 있습니다. 푸시 연결이나 즉시 전달 보장은 아닙니다. 메일 발송은 이 버전에 포함하지 않습니다.

## 접근 범위

알림함은 본인의 대화형 로그인 세션에서만 사용할 수 있으며 API 키로 접근할 수 없습니다. 현재 검사·검토 접근 권한을 서버에서 재확인하므로 검토 자격을 잃으면 관련 검토 요청 알림과 미읽음 개수에서도 제외됩니다. 관리자에게도 다른 사람의 개인 알림함은 노출하지 않습니다.

알림은 사건 유형, 권한을 확인한 현재 소스 이름, 판정과 시간만 표시합니다. 코멘트 본문, 검토 사유, 원본 스캐너 오류, 코드나 인증정보를 알림에 복제하지 않습니다.

## REST 계약

아래 API는 모두 로그인 세션과 `X-AAG-Account` 헤더(화면에 표시한 사용자 ID)가 필요하고 변경 요청은 기존 same-origin 검사를 따릅니다. 헤더와 현재 세션 계정이 다르거나 헤더가 없으면 409로 거절합니다. 브라우저는 계정 변경과 세션 만료 때 기존 화면을 비우고 현재 계정을 다시 확인합니다.

| API | 동작 |
| --- | --- |
| `GET /api/notifications` | `state=all\|unread\|archived`, `category=all\|scans\|reviews\|comments`, `page`, `page_size`로 조회 |
| `GET /api/notifications/unread-count` | 보관함·만료·권한 제외 후 미읽음 개수 |
| `PATCH /api/notifications/{id}` | `{"read":true}` 또는 `{"archived":true}`; false로 되돌리기 |
| `POST /api/notifications/read-all` | `{"category":"scans","before":목록의_snapshot_at,"through":목록의_snapshot_sequence}`으로 조회 시점까지 일괄 읽음 |
| `GET /api/notification-preferences` | 본인의 수신 설정 |
| `PUT /api/notification-preferences` | `scans`, `review_requests`, `review_results`, `comments`의 boolean 필드 부분 변경 |

목록은 `items`, `total`, `unread_count`, `filtered_unread_count`, `snapshot_at`, `snapshot_sequence`을 반환합니다. 기본 페이지 크기는 25개, 최대 100개입니다. `unread_count`는 유형 필터와 무관한 개인 전체 미읽음 개수이며 `filtered_unread_count`는 선택 유형의 미읽음 개수입니다. 시간은 Unix 초입니다. 수신자 ID를 입력하거나 다른 사용자의 항목을 변경하는 기능은 없습니다.
