---
title: 공지·VOC와 운영 공개
---

`AAG_BOARDS_ENABLED=false`가 기본값입니다. false일 때 메뉴, 목록, 상세, 작성, 댓글 API가 모두 차단됩니다. 기능을 개발/검증하는 동안 stg에 노출하지 않고 별도 개발 환경에서 true로 검증하세요.

공지는 관리자만 작성하고 초안을 저장할 수 있습니다. 내부 검토는 검토자/관리자만 접근합니다. VOC는 일반 사용자도 작성하며 공개/비공개를 선택합니다. 비공개 글은 작성자와 운영 직원에게만 표시합니다. 상태는 open → triaged → planned → in_progress → resolved / closed로 분류하고 직원이 변경합니다. 저장된 원문은 Markdown이고 클라이언트는 raw HTML을 해석하지 않습니다. 외부 이미지는 추적 방지를 위해 렌더링하지 않습니다.

읽음은 사용자·글 revision에 연결됩니다. 글이 갱신되면 다시 미확인으로 나타납니다. 편집은 revision 일치가 필요하여 다른 사람의 수정 사항을 덮어쓰지 않습니다. 내부 코멘트는 서버가 읽기 권한을 검사합니다.

공개 전 실제 역할별 사용 흐름, 사내 SSO, 프록시, 폰트, 키보드 접근, 오류/빈 상태, 장문 Markdown을 검증하고 운영 설정으로 flag를 켜세요. 플래그를 켜는 것을 자동 배포 완료 조건으로 삼지 않습니다.
