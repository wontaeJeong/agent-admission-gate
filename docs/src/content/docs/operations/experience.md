---

비로그인 루트 \`/\`은 정적 제품 소개를 표시한다. \`/login\`은 기존 인증, 로그인 후 \`/\`은 대시보드이며 \`/about\`에서 소개를 다시 볼 수 있다. 실제 정책·스캐너 결과를 시연 데이터로 꾸미지 않는다.

\`/coverage\`는 관리자에게 Gate 기능의 대표적인 구현 근거와 남은 운영 인수를 링크한다. **전체 요구사항 합격판정 UI가 아니다.** 원본 요구사항은 [requirements.md](requirements.md)를 참조한다.

Hub 공통 UX: 공개 제품 정의/도입 이유, 단계별 작업 맥락, 구현/미검증 명시 구분, 역할별 콘솔 탐색, 모바일 대응, 키보드 사용 가능한 표/필터. Hub의 조직·위키 자료 편입·지식 발행 개체는 Admission Gate 업무가 아니므로 잘못된 기능으로 복제하지 않는다.
