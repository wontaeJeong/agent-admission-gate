# 검사 결과 비교 개선 설계

## 목적과 범위

검토자가 저장된 검사 결과의 중요한 변화와 비교 한계를 빠르게 이해하고 분류별 결과를 찾도록 한다. 모바일 레이아웃 개선은 범위 밖이다. 기존 디자인, 한·영 문구, 권한과 판정 의미를 유지한다.

## 대안과 선택

- 변경 요약을 제한사항 바로 뒤로 옮기고 분류별 필터로 연결한다. 결과 배열 전체에 필터를 적용한 뒤 페이지를 나누므로 50개 이후 항목도 찾을 수 있다. 요약 수치는 전체 범위로 유지한다. 이 방식은 요약과 탐색을 연결하며 현재 API 변경이 필요 없다.
- 표 내 바로가기만 추가하면 많은 항목에서 분류에 맞지 않는 행을 계속 넘겨야 한다. 별도 서버 필터는 이미 내려온 최대 1,000건에 비해 API와 권한 검증 범위를 불필요하게 넓힌다.

## 동작

1. 비교 한계와 미검출 경고는 제일 먼저 유지한다. 완료된 비교에는 그 뒤에 전체 관측 변화 요약을 배치하고, 세부 메타데이터와 발견 표를 계속 제공한다. 실패·취소 검사는 요약 없이 메타데이터만 유지한다.
2. 전체와 다섯 분류 중 하나를 선택해 결과를 필터링한다. 선택 시 첫 페이지로 이동하고 선택과 결과 범위를 시각 및 접근성 상태로 전달한다. 결과 없음, 0건 분류, 대상 쌍 변경 및 페이지 경계를 처리한다.
3. 정확 일치, 이동 후보, 일치 불명, 예외 적용의 뜻을 결과 가까이에 간결한 한·영 설명으로 제공한다. 미검출이나 일치 후보를 해소·확정으로 표현하지 않는다.
4. 데스크톱의 변경 값과 분류를 쉽게 구분하도록 기존 토큰·컴포넌트 안에서 위계를 조정한다. 작은 화면의 기존 배치 규칙은 변경 대상이 아니다.

## 검증

필터 적용 순서·초기화·빈 결과·범위 표시와 실제 브라우저의 데스크톱 화면, 한·영 문구, 실패·취소 및 접근 가능한 조작을 검증한다. 백엔드 정책과 응답 형식은 변경하지 않는다.
